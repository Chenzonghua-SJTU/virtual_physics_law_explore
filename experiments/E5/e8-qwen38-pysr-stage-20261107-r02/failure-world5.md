# R02 世界 5 失败复核

结论：工具内部已经生成完整三次结构，现有轨迹拟合器也能把它拟合到数值精度。失败发生在单轴候选筛选早于联合参数共享、完整结构没有作为可直接拟合的五参数候选交付，以及 Agent 将六个项误当成必须有六个独立参数。原始自主探索成绩仍为 64.3331 分，本报告中的诊断回放不替代这次成绩。

## 原始实验

源码 `174dff5`；运行 `e8-qwen38-pysr-stage-20261107-r02-world_5`。探索 271.109 秒，含启动和独立测评共 276.033 秒；23 次模型调用，平均每次输出 449.043 token，最大单次输出 1412 token。

第一次 SR 只用了两条免费短轨迹，合计 12 个内部差分点，时间覆盖 0–1，尚不足以区分复杂候选。第二次 SR 使用 probe_0003/0005/0006，144 个内部点，覆盖 0–4.9；在这一次搜索里，通用多项式回归分支 `regression_basis` 已经给出：

```text
ax ≈ -0.06000876*x - 0.00199904*x^3 - 0.01198824*x*y^2
ay ≈ -0.10000093*y - 0.01198497*x^2*y - 0.00200440*y^3
```

不能把这两条都表述成“PySR 后端找到”：展开式来自 `regression_basis`。PySR 后端也找到了数值上等价的 ay 因式分解形式。因此这里有完整结构的搜索证据，不是从公开真值手写公式补进去。

## 候选筛选丢掉了可共享的写法

`shore_agent/symbolic_regression.py` 的 `_prepare_axis` 先分别按单轴误差、复杂度和参数数量做 Pareto 筛选；随后 `_select_candidates` 才配对两轴并尝试共享参数。

- 正确 ax 展开式进入配对阶段。
- 正确 ay 展开式没有进入配对阶段。它被复杂度更低的等价因式分解式，以及在差分数据上误差略低的三角近似支配。
- 因式分解把系数变成差值、改变符号，使当前“同号且数值接近”的共享提议不能识别与 ax 的交叉项系数关系。
- 本来六个系数中，两轴交叉项约 0.01199 可以经数据检查后共享，得到合法五参数公式；筛选后这个机会消失了。

最终返回的第一条完整候选有五个参数，但 ay 少了 y³。它不是对完整六项公式直接删项，而是从合法配对中选中了更短的结构。公开单轴候选列表仍保留了正确的因式分解 ay，Agent 有可能从中整理出完整公式，但没有做到。

原始第二次 SR 记录：`records/symbolic_search/sr_4a250f50be8e.json`。筛选重放、支配关系、共享检查及参数都保存在本目录 `failure-world5-packaging.json`。

## Agent 没有补回缺项

原始 `tools.jsonl` 第 7 行拟合缺 y³ 的 law_3，训练位置 RMSE 为 0.001240；第 9 行在新取得的 probe_0007/0008 上验证，位置 RMSE 为 0.017833，已明显暴露泛化问题。

第 10 行 Agent 尝试补齐结构，但用了六个独立参数，触发最多五参数的校验。后续没有复用两轴交叉项参数，而是重复调整不完整公式，或错误地把不同幂次的系数绑在一起。最终仍封存 law_3。改变拟合初值和重复最小二乘，无法补回公式中不存在的 y³ 项。

## 只使用已有观测的诊断回放

这不是新一轮自主探索，也没有调用 Qwen、启动 PySR 搜索、采集新世界观测或重跑官方案例评分。只从搜索记录中取回上述完整展开式，检查现有共享逻辑和拟合器是否足够：

1. 对原第二次 SR 的 discovery 数据单独重放一次共享参数检查，耗时 0.257 秒，得到五参数候选；训练分组与 discovery 内整探针留出检查均通过。该留出不是独立验证。
2. 用 law_3 原训练轨迹 probe_0003/0004/0005/0006，重放一次现有轨迹拟合；另用已经获取的 probe_0007/0008 验证，未将它们用于拟合。拟合加这次回放总耗时 0.347 秒，状态 converged。

```text
ax = -(c1*x + c2*x^3 + c3*x*y^2)
ay = -(c4*y + c3*x^2*y + c5*y^3)

c1 = 0.059999999676
c2 = 0.002000000053
c3 = 0.012000000224
c4 = 0.099999999235
c5 = 0.002000000141
```

| 已有观测上的位置 RMSE | 原 Agent law_3 | 诊断完整五参数式 |
|---|---:|---:|
| 原训练轨迹 | 1.2400e-3 | 7.9674e-9 |
| 原验证轨迹 | 1.7833e-2 | 6.5631e-9 |

这证明“完整候选能被现有拟合器拟合”，也定位了候选交付的缺陷。它不证明修复后 Agent 一定在 300 秒内自主选择正确公式；该问题仍需后续冻结实现后重新测量。诊断不修改原提交、原分数或原模型调用记录。

## 最小修复方向

1. 在单轴 Pareto 删除前保留可共享的等价参数化，或对多项式作有界展开、系数归一，再按联合独立参数数目筛选。
2. 对接近系数的共享继续做已有 discovery 分组检查，不假定对称性或把系数强行设成相等。
3. 返回可直接调用 `fit_law` 的完整五参数向量候选，减少 Agent 手工整理代数式的负担；不放宽参数上限，不加入世界 5 专用公式。

上述生产修复尚未实施；此次只修复只读审计对空错误字段的兼容性并归档证据。
