世界 02 恢复带 charge/mass 的线性恢复力；世界 03 恢复交叉线性项。其余四世界不能称恢复成功。差分标签误差仅约 2.8e-6 至 1.7e-5，因此当前失败主要不能归于速度差分或 Agent。世界 01/04 训练误差低而留出误差很大，暴露局部拟合与外推失败。世界 02/03 的差分组在候选前沿中已有简单正确结构，最低训练损失仍可能偏好冗余微小修正。

这是单次随机搜索和有限轨迹覆盖下的结果，不证明 PySR 原理上无法解决。24 条轨迹不等于空间均匀覆盖；初始半径 1.5–4 对 0.05 软化尺度的微小修正辨识力有限。低预测误差也不能直接当成精确符号恒等式恢复。本次离线数据量超过一场 Agent 的能量预算，不能替换原 baseline。
