# E5：在 300 秒和 4096 token 内恢复无噪声六世界基线

目标是在**同一批六个世界**中至少五个取得本地分数 ≥90，同时每场探索不超过 300 秒、每次模型调用输出不超过 4096 token。E5 继续严格保留 10 能量；探索观测先关闭噪声，独立测评始终使用无噪声轨迹。R01、R02、R03、R04 分别达到 3/6、2/6、1/6、1/6，均未达到目标；R04 有两场未提交。R05/R06 已完成同一冻结版本的诊断工具开关对照：关闭组 0/6、开启组 3/6，仍未达到五世界目标。R07 的紧凑诊断与重复失败提醒实验为 2/6，另有两场未提交。R08 按预算展示工具后为 3/6；两场未提交，另一场候选评测失败，目标仍未达成。

这是 v15 六个公开开发世界上的自主探索和本地适配器评测，不是正式赛事成绩。每批每世界只运行一次，不自动重启会话、不恢复上一场探索，也不跨批挑选最好分数拼成一轮。90 分是本次用户设定的复现目标，不是官方通过线；达标判断使用未四舍五入的原始分数。

## 计时与 token 口径

- **探索耗时**从首次 mission 开始，包含模型调用、科学工具、提交检查与会话收尾；300 秒限制针对探索阶段。有效提交或保存配对必须在截止前通过检查，截止后的封存不能进行新推理、拟合或补写声明。
- **总耗时（含评测）**采用每个 worker 的实际墙钟时间，包含启动/收尾及独立评测，不含等待空闲模型端点的排队时间；因此不等于探索耗时与评测耗时的简单相加。独立评测在探索结束后进行，不占探索的 300 秒。
- **平均输出 token/调用**在 usage 完整时，为 API 报告的 completion tokens 总和除以模型调用数；若有调用缺少 usage，则全调用平均值记为未知，不把缺失输出按零计算。最大输出检查每一次请求，不以平均值代替 4096 上限。截断调用也计入耗时、调用数及已回报 token。
- 四卡并行后，整批墙钟时间、六个 worker 总耗时之和、单场 300 秒限制是三个不同口径。
