# v15 六世界 Qwen3.8-27B 无思考 baseline：最终分析

本轮六个世界各运行一次：**4/6 提交并完成全部独立评测，2/6 未完成；仅世界2达到位置 RMSE < 1e-6 的高精度标准，即 1/6 次探索、1/4 个已提交结果。** 世界1、4、5虽然提交被本地接口受理，公式仍有不同程度的结构错误。不能将提交率或高分直接解释为精确规律发现率。

运行时间为北京时间 **2026-11-07 03:54:02—04:06:32**，最多三世界并行，总历时约 **749.58 秒（12分30秒）**。本报告依据[冻结清单](manifest.json)、[机器汇总](summary.json)、[自动报告](report.md)及本机各运行档案进行事后审阅，没有更改探索记录、评分或冻结实现。旧思考模式 R01 已按用户要求中断保留，不混入本轮。

## 设置与结果口径

模型为 `qwen3.8-27b`，通过百炼兼容接口调用；六局有效配置均为 `thinking=false`、无噪声、seed=42。每局仍为 100 能量、3600 秒、5M 总 token、65536 单次输出上限，代码工具关闭。主 Agent 科学探索循环、提示词、工具 schema、表达式与拟合逻辑不作额外修改。每世界只尝试一次，不补跑失败局。

四个受理提交分别完成 24 条原 v15 固定案例轨迹，共 96 条；世界3、6没有提交，因此没有独立评测分数或 RMSE，表中的“—”不是零分。真值使用 v15 固定积分器，候选继续使用现有 Agent 数值工具。分数为本地 `P+L+C`：`P=80/(1+10*MSE/V)`，三项声明各5分，只有 `P≥40` 才有 `C=5*(1-E/100)`。它不是官方成绩，也不是 v15 标准10能量会话的分数。

## 世界1：恢复主要距离趋势，但漏掉软化项

提交 [law_3](../../runs/v15-qwen38-nothink-baseline-20261107-r02-world_1/records/law/law_3.json) 等价于

`a = -k*(charge/mass)*r_vec/r²`，`k=0.07950502332802203`。

实际规律的向量分母为 `r*sqrt(r²+0.05²)`，前系数为 `1/(4π)=0.079577471546`。候选识别了向心作用、属性比例和近似 `1/r` 幅值，却遗漏软化尺度；拟合系数还比真实前系数低约0.091%。记录中的三个候选只尝试了未软化的两种幂律，没有探索软化参数。

无噪声训练 RMSE 已为 `1.52973e-4`，内部验证为 `6.46740e-5`；完整评测扩展到较长轨迹后为 `0.00345018`。它不是数值精度内的精确恢复。

**为什么仍有99.399764分？** 其 `MSE=1.19038e-5`，真值位置总体方差 `V=40.2922`，归一误差仅 `2.95436e-7`，所以预测分为 `79.99976365`。三项声明正确得15分，消耗12能量得4.4节约分，合计99.39976365。三项声明分检查动力学阶数、隐藏物质和显式时间依赖，不验证完整公式是否恢复。

只读事后诊断中，保留未软化形式、仅换用真实前系数，RMSE仍为 `0.00214813`；使用完整真规律的开发者对照降为 `6.25270e-8`。这些内存计算没有改写提交或评分，也不计入 Agent 成果；它们支持误差来自模型结构近似而非本次积分精度下限的判断。

## 世界2：本轮唯一达到高精度的完整恢复

提交 [law_2](../../runs/v15-qwen38-nothink-baseline-20261107-r02-world_2/records/law/law_2.json)：

`a = -A*(charge/mass)*r_vec`，`A=0.05999999999536216`。

形式和属性比例与真规律一致，系数接近0.06。24条完整评测位置 RMSE 为 `3.96833e-8`，通过本报告 `1e-6` 精度标准。预测分接近80、声明15、节约4.25，总分99.25。它的分数略低于世界1，只因多消耗三点能量；不能按这两个总分的大小排序公式精确度。

## 世界3：持续停留在错误候选结构，预算阻止下一次请求

最终原因是 `model_token_budget_exhausted`。已返回用量为4,850,752，距5M仍有149,248，但下一次请求估计输入需要212,727 tokens，已超过剩余预算，因而在发送前被阻止。这不是恰好消费到5,000,000才结束，也不是60分钟或能量耗尽。

探索中产生22个规律版本，全部采用同一种对可见天体求和的径向候选结构，另有14次验证；没有提交。真规律是固定主轴旋转后的各向异性线性回复矩阵，当前候选族没有覆盖该结构。还出现一次调用未启用 `run_code` 和一次表达式常数错误。上述记录说明候选搜索停滞并扩大了消息历史；本轮不能提供该世界的最终预测分数。

## 世界4：短时局部拟合掩盖了错误衰减形式

提交 [law_5](../../runs/v15-qwen38-nothink-baseline-20261107-r02-world_4/records/law/law_5.json) 的径向幅值为

`(charge/mass)*C/(r+d)²`，`C=0.6725381292781443`、`d=0.6450282679702947`。

实际幅值为 `(charge/mass)*exp(-rho/4)/(π*rho)`，其中 `rho=sqrt(r²+0.05²)`。候选把指数屏蔽近似成另一种幂律衰减，六个规律版本均未尝试指数屏蔽项。其文字解释还把 `law_2` 称作平方反比力，但该版本实际向量式为 `-C*r_vec/r²`，幅值是 `1/r`；这也说明公式与文字解释需要分开核对。

训练11条轨迹的初始半径主要为1—4，最长跨度仅1.9，训练 RMSE为 `0.00049978`。最后一次内部验证的 `0.00079804` 只对应两条中等半径轨迹，跨度均为2.8；它并不代表所有内部验证。另一次包含初始半径5的三条轨迹验证已为 `0.00368864`，其中半径5那条为 `0.00529906`。

独立评测使用30的轨迹跨度，初始半径覆盖至8。此候选幅值在半径1、2附近与真值接近，在半径5高估约15.7%，半径8高估约67.1%；长时间推演使结构偏差积累。三个距离分组的位置 RMSE分别为0.2340、0.3294、0.8892，最差单轨迹为1.7156，全体为0.563891。短程验证与完整评测之间约706倍的 RMSE差距，因此有明确的覆盖范围与公式结构解释，不能归因于评测器故障。

评分仍得到91.331235，是因为 `MSE/V=0.0103734`，预测分72.481235，加三项声明15和节约3.85。该结果应记作近似模型提交，不能称为精确恢复指数屏蔽规律。

## 世界5：已取得的数据足够，但假设搜索和选模失败

提交 [law_1](../../runs/v15-qwen38-nothink-baseline-20261107-r02-world_5/records/law/law_1.json) 为 `a=-0.1072311097797815*r_vec`。真规律包含不同方向的线性系数、自身三次项及交叉三次项：

`ax=-0.06*x-0.002*x³-0.012*x*y²`

`ay=-0.10*y-0.002*y³-0.012*y*x²`。

本局31次拟合请求中，首个畸形表达式被拒绝，其余30次均返回收敛。随后候选只在线性和线性加阻尼两类之间变化：同一 `probe_0004`、相同参数的单系数拟合重复18次；同一 `probe_0007` 的阻尼拟合重复5次。消息档案表明它们来自不同模型回复与不同工具调用ID，前次结果已回传，并非编排器自动重跑。

最早内部验证 RMSE 已达0.16247，模型仍回选首光拟合的 `law_1`。提交时尚余94能量、3443秒和约1.35M总 token，不能用资源耗尽解释提前提交。任务明确为位置、速度均零噪声，最终说明却以“当前噪声与差分精度”弱化系统残差。只用同一质量、同一投放时刻的实验，也不足以严格支持其关于质量、时间无关性的全部论证。

只读事后诊断给定完整四参数结构，用原有拟合器和本局已取得的 `probe_0001—0006`，得到参数约 `0.0600000000、0.1000000000、0.0020000000、0.0120000000`，训练 RMSE `5.22e-9`；再对未参与该诊断拟合、但本局已经取得的 `probe_0007/0008` 推演，RMSE `1.03e-8`。因此，数据及现有 DSL、数值工具支持该结构；本次失败不能直接归因于工具不支持三次项或观测无法辨识。**这是开发者提供结构的事后诊断，不是 Agent 自主发现，不计入结果表。**

完整评测24条轨迹均成功执行，RMSE为1.580360，预测分16.862476；三声明得15分，因预测分低于40没有节约分，总分31.862476。它是科学预测失败，不是提交格式或积分执行失败。

## 世界6：表达式修正停滞，随后HTTP 400结束

本局35次拟合请求中有33次 DSL错误：9次 `bx` 超出作用域，24次违反数字常量规则。第20—39次模型调用的工具参数逐字重复，反复返回错误；最终以 `http_status_400` 结束，未提交，也没有独立评测。

结束前请求的离线消息核对中，81条消息的40个工具调用ID均唯一且正确配对，未发现缺失工具回复等协议结构错误。HTTP 400的响应正文未保存，无法从现有证据确认其具体原因，不能直接归因为上下文超限、工具配对错误或关闭思考本身。另一次在基准之外对同请求的诊断等待响应头约60秒后超时，未获得400原因、未执行工具且未返回 usage；它不纳入本轮六局统计。

## 可支持的结论与复现

本轮验证了旧 Agent 科学核心能在新版世界中运行、提交和评测，但六个世界中只有世界2精确恢复；世界1漏软化项，世界4衰减结构错误，世界5漏非线性与方向差异，世界3/6未完成。反复调用相同工具与短时局部验证后过早提交，是本次记录中可定位的问题。每世界仅一次试验，且旧思考批次没有完整运行，不能据此估计稳定成功率或推断关闭思考的因果效果。
