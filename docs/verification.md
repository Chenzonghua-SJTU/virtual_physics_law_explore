# 开发验证报告

验证日期：2026-11-01。环境：macOS ARM64、Python 3.9.6、CPU；精确依赖见 `../requirements-tested.txt`。原始附件仅用于开发，未发送给运行时模型。开发人员完成原型代码，实际科研主循环由 DeepSeek API 驱动，没有使用 Coding Agent 作为运行时科研 Agent。

## 实际交付

- 独立仿真子进程、免费第一束光、无噪声/位置噪声、资源/时间网格限制。

- 主 Agent 循环及独立一次调用分析模型；自动工具选择、自然进展、完整思考和工具消息配对、统一模型预算和有限重试。
- 独立评测、关键测试、安装配置及工具文档、完整运行记录。

## 独立分析模型的真实诊断

- `live-analyst-001`：真实一次 API，思考占满 4,096 token，报告不完整，工具明确失败；实际总 token 6,598。
- `live-analyst-002`：改为非思考模式，返回完整 JSON；某些统计现象没有精确证据引用，报告遭拒。自然语言中也出现了未经过程序计算的数字，因此进一步加强了证据检查；实际总 token 4,894。
- `live-analyst-003`：补齐方法/噪声上下文、可引用的统计证据，并限制报告长度与数值出处后，返回三条现象、三份原样证据。原检查器将候选符号式中的 `p-1` 结构常数误判为编造数值；修复并增加回归测试后，直接对同一份真实回复确定性重检成功。没有追加模型调用，也没有重写原失败记录；见 `runs/live-analyst-003/revalidation.json`。该次实际总 token 5,290。

分析子 Agent 的网络调用、报告生成和引用核验均有真实记录，但成功结论准确表述为“保存的真实报告在修复后的检查器下重检通过”，不能说它曾被这次自主主 Agent 调用或在原有代码下直接成功。

全部真实运行共七次 HTTP 请求，服务端报告合计 69,474 token。各会话有效配置、输入与回复、用量、耗时和失败原因均保留。扫描源码和运行文本未发现 API Key 格式的凭据；密钥只通过隐藏输入注入短期进程环境，未写入配置、代码或日志。
