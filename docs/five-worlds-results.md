# 五世界首轮真实 Agent 测试结果

2026-11-02，上海时间 16:31:47–16:36:56。本轮五个世界各尝试一次，完成全部计划，其中 **1/5 自主提交并完成独立评测**。其余四次未提交，未替换为手工公式、未扩预算、未重跑。单次试验不能估计各世界的稳定成功率。

## 同一框架、同一协议

仅世界的力场不同。模型、两份提示词、8 个工具、拟合器、表达式语法与实验资源限制不变。每次独立进程运行，不共享前一个世界的对话或规律。Agent 只获取中性世界编号及合法观测，没有收到真实公式或开发文档。

- 模型：`deepseek-flash`，主 Agent 开启 `thinking`、`reasoning_effort=low`；分析 Agent 关闭思考。
- 每世界预算：总 24 次 HTTP 尝试（主 Agent 20、分析 Agent 4）、300,000 token；单次主回复最多 8,192 token。
- 环境：无噪声、种子 42、100 点能量；初态与时间范围一致。
- 提交后评测：种子 1871、20 条未见初态，无观测噪声。未提交的会话不运行隐藏评测，也不填零分。
- 供应商模型为可变别名；保存了响应模型标识、配置和提示词 SHA-256，不能保证再次运行得到相同输出。

## 失败原因与能力边界

**世界 01：成功预测新初态。** 模型提出 `ax=-k*sum_b(x-bx)`、`ay=-k*sum_b(y-by)`，拟合 `k=0.09999999987537979`。完成 6 条新实验验证后自主提交 `law_1`。独立评测误差很低；这证明该版本的预测能力，不证明其作用源解释唯一，模型关于排除其他源结构的文字结论仍需要谨慎理解。

**世界 02、03、05：思考消耗单次输出额度。** API 返回 `finish_reason=length`，对应思考 token 分别为 8,191、8,192、8,192；正文为空，工具调用为空。框架如设计拒绝执行截断回复并结束。因此，这三次尚未进入假设的实验检验，不能解释为已经证明模型无法识别对应力场。调高总 token 上限本身不会解除单次输出上限。

**世界 04：表达式试错与预算管理共同限制。** 发生 10 次拟合调用，其中 4 次超过 100 个 AST 节点、1 次违反常量语法限制；一次分析 Agent 报告也超出格式条目限制。最终生成 5 个规律版本（含失败拟合），投放 8 条新轨迹并执行一次验证。`law_5` 训练位置 RMSE 约 0.00657，验证位置 RMSE 约 0.22723，尚不能解释全部已有观测。该验证使用早先看过的第一束光，只是开发诊断，不是最终新留出检验。记录中没有成功提交。

世界 04 实际用了 217,816 token，低于 300,000；停止原因是完整历史增长后，下一次请求的保守输入加输出预留已无法放进剩余预算。它不是“实际使用恰好达到 30 万”。

详细工具错误与回复用量计数见 [diagnostics.json](../benchmarks/five-worlds-live-001/diagnostics.json)。报告没有复制模型的隐藏思考内容。

## 已实现与已验证

- 前端可选择五个世界，运行中禁改；历史、详情、回收站和恢复保留所属世界；旧会话归入世界 01。
- 五个力场均通过独立参考轨迹、守恒量、边界初态、噪声、预算和进程隔离检查。03/04 使用独立高精度数值参考，不宣称解析解。
- 现有 DSL 和数值工具均可表达、拟合并验证五个世界的规律。该项使用测试中手工指定的结构，只证明工程管线能够处理，不计为自主发现。
- 全部 322 项离线测试通过（303 项完整回归加随后新增的 19 项基准/评测测试），JavaScript 语法及浏览器世界选择、所属世界显示检查通过。

当前自主发现的首要改进方向是单次输出预算与截断后的受控恢复，其次是表达式复杂度反馈和历史上下文用量。任何改进都应以同样的五世界协议另开新批次对照；本轮基准保留原配置，不把后续改进混入本轮成绩。
