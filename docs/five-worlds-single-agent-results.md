# 删除分析子 Agent 与 summarize_data 后的五世界测试

2026-11-02 19:37:01–19:49:42（上海时间）。五个世界各运行一次，**5/5 自主提交并完成独立评测**，每个世界均完成 20 条未见初态轨迹。没有手工补公式、补提交、重跑或在运行中修改预算。

## 本轮架构

删除了 Analyst 类、分析提示词、分析专用配置、CLI 诊断命令，以及 summarize_data 的工具声明与运行时实现，没有用其他摘要工具替代它。新运行只有一个主 Agent 和七个工具：

`observe_body`、`insert_probe`、`fit_law_and_rollout`、`validate_law`、`call_back`、`analyze_residual`、`submit`。

模型客户端仅允许 main 角色。主提示词移除了分析委派和相关描述，并将工具数改为七个；未增加任何力场答案、候选提示或世界专用策略。旧会话和分析报告的网页展示/导出仍兼容，历史原始文件未改。

## 统一测试配置

- deepseek-flash，thinking=true，reasoning_effort=low。
- 每世界总预算 2,000,000 token，单次输出 65,536，请求超时 600 秒。
- 总调用上限仍为 24；上一轮主 Agent 20/分析 4，本轮全部 24 次供主 Agent 使用。实际最多 7 次，没有触及新增的主 Agent 调用额度。
- 噪声关闭、种子 42、100 点能量、现实时间上限 60 分钟；力场和数值工具不变。
- 提交后评测种子 1871，每世界 20 条未见初态；模型不能获取隐藏真值或评测结果。

两轮均 5/5 提交并完成评测。总模型请求从 35 次降至 30 次；实际 token 从 1,146,252 降至 1,006,152，本轮减少 12.2%。各世界不是一致改善：世界 02 用量增加，世界 04、05 的误差略高，但所有提交的预测误差仍很低。

这是每世界一次的工程复测，不是稳定成功率估计，也不能把全部用量变化归因于删除子 Agent。工具集合、主提示词和主调用分配发生了必要变化，模型采样存在随机性。结果支持当前五世界任务可由单 Agent 加数值工具完成；不证明所有更复杂任务均无需多 Agent。

## 最终规律与试错

完整表达式和参数见 summary.json 的各世界 law 字段。世界 01 找到线性天体求和；世界 02 用对三个天体的线性求和表示耦合力场，展开后与真实线性矩阵一致；世界 03 找到线性加三次回复力；世界 04 找到软化多源吸引力。

世界 05 提交了回复力、速度偏转，以及额外的旋转位置项和阻尼项。后两者系数分别约 3.85e-11 和 7.47e-9，接近零；核心回复系数和速度偏转系数分别约 0.3、0.45。预测一致不证明力源解释唯一。

本轮只记录到一次工具失败：世界 04 的候选表达式超过 100 AST 节点，主 Agent 根据错误自行修正。没有回复截断或分析子 Agent 错误。

## 工程验证

完整离线回归 **305 项测试通过**，JavaScript 语法检查通过。删除的工具不可被运行时执行，已删除的分析角色在发起 HTTP 前被拒绝。旧版网页记录保持可读，新的调用指标标为主 Agent 模型请求。
