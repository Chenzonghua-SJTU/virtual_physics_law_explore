# 扩大预算后的五世界真实 Agent 测试

2026-11-02 16:55:17–17:08:07（上海时间）。五个世界各运行一次，**5/5 自主提交且完成独立评测**；每个提交版本均完成 20 条未见初态轨迹，位置 RMSE 均低于 9e-8。没有手工补公式、补提交或替换失败尝试。

## 为什么首轮会截断

首轮世界 02、03、05 的首次回复分别用了 8,191、8,192、8,192 个思考 token，触及原型设置的 8,192 单次输出上限。供应商返回 length，正文与工具调用为空。总预算和单次输出是不同限制：增加总预算不能直接解除单次截断。

本轮主 Agent 单次输出提高至 65,536，总预算提高至每世界 2,000,000，请求超时从 90 秒提高至 600 秒。分析 Agent 仍关闭思考且输出最多 4,096。网页高级设置增加独立的单次输出控件。旧会话保留原配置。

模型仍为 deepseek-flash，主 Agent 开启思考、low 强度；总调用最多 24（主 20、分析 4），噪声关闭，种子 42，现实时间 60 分钟。工具、DSL、数值拟合、环境能量与评测协议均不变，两份提示词 SHA-256 与首轮完全相同。Agent 未获得私有力场公式或隐藏评测反馈。

## 截断与其他错误

本轮没有 length 截断。世界 05 首次回复输出 8,927 token，其中思考 8,438，已超过旧的单次上限。世界 03 某次输出 13,098，世界 05 最大输出 14,974，均正常完成工具调用。

仍发生可恢复错误：世界 02、05 的分析工具各一次 JSON 格式错误；世界 03 一次公式常量语法错误；世界 04 一次超过 100 AST 节点。主 Agent 根据工具返回继续探索并自行纠正或绕过，未改变 DSL 限制。

扩大预算有效移除了本轮的截断瓶颈，但未消除格式错误。调用与 token 成本仍应在后续多随机种子试验中统计。独立评测只在会话结束后运行，未反向指导本轮模型。
