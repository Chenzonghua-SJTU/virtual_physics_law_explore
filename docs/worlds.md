# 七世界物理规律发现

控制台的「探索世界」可选择世界 01–07。每次会话固定在一个世界中，已有会话不能切换世界；历史记录和回收站保留所属世界。未记录世界编号的旧会话归入世界 01。

七个世界共用同一套主 Agent 提示词、7 个工具和数值拟合方式，已移除分析子 Agent 与 summarize_data。初态范围、物理时间网格、观测噪声、100 点能量及其余实验限制一致。前三个可见天体的初始位置为 `(-2,0)`、`(2,0)`、`(0,3)`；世界06中天体移动，其余世界保持静止。

v4按题目提供可见天体编号、已知t=0位置与速度，以及免费第一束光：两条探针各8时刻的位置与速度、同8时刻的可见天体位置。第一束光不扣能量或observe额度，重复mission返回缓存。后续位置只能通过 `observe_body(times)` 取得，不提供源运动公式、未来位置或真实力场。尚未加入随机初始布局或跨布局评测。历史v1–v3保留原观测协议，不作为v4的自主探索测试结果。

## 开发者的力场定义

以下公式仅供开发者检查，不能作为运行时 Agent 的任务材料。界面和任务包只提供中性世界编号，不提供力场类型、公式或系数。私有定义位于 `shore_sim/worlds.py`，拟合工具不能导入它。

当前物理与观测协议版本为 `v4`。原五世界力场保持v3定义，世界05仍为 `g=1, s=1`。令 `delta_i(t) = b_i(t)-r`、`rho_i² = delta_i·delta_i`、`Rv=(vy,-vx)`，`b_i(t)` 为三个可见天体的瞬时位置。每个天体贡献独立作用后求和；探针质量和电荷在这七个世界中不影响加速度。

| 编号 | 力场 | 真实加速度 |
|---|---|---|
| 世界 01 | 逐源线性弹性吸引 | `a = Σ 0.1 delta_i` |
| 世界 02 | 逐源各向异性弹性作用 | `a = Σ A delta_i`，`A=[[0.35,0.08],[0.08,0.20]]/3` |
| 世界 03 | 逐源非线性弹性吸引 | `a = Σ (0.06+0.004 rho_i²) delta_i` |
| 世界 04 | 软化的多源吸引力 | `a = Σ 0.8 delta_i/(rho_i²+0.64)^(3/2)` |
| 世界 05 | 逐源弹性吸引与随距离衰减的速度偏转 | `a = Σ [0.1 delta_i + 1/(rho_i²+1) Rv]` |
| 世界 06 | 移动源的线性回复作用 | `a = 0.1 Σ [b_i(t)-r]`，`b_i(t)=b_i(0)+(0.08,-0.04)t` |
| 世界 07 | 固定源、周期强度的线性回复作用 | `a = [1+0.5 sin(0.6t)] · 0.1 Σ [b_i(0)-r]` |

世界 01、04 的物理不变；世界 02 在当前三天体布局下与旧线性场等价。世界 03 的单位质量势能为 `Σ(0.03 rho_i²+0.001 rho_i⁴)`。世界 05 的速度项与速度垂直、不做功，守恒量为 `|v|²/2+0.05Σrho_i²`；它是虚拟偏转作用，不宣称实际电磁机制。世界 02 的单源力可不沿连线。软化项使世界 04 在天体位置处仍有有限加速度。这些是本地开发环境，不是正式比赛宇宙。

世界06采用最简单的共同匀速平移，使源质心确实移动；否则在线性叠加下，质心不变的天体运动可能不改变探针受力。该世界在固定瞬时天体位置和探针状态后没有显式时间项，正确声明为 `time_dependence=false`。其相对移动质心的谐振能量守恒，实验室坐标中的探针机械能一般不守恒。世界07固定天体仍有显式时间项，声明为 `time_dependence=true`；势能随时间变化，探针机械能一般不守恒。周期系数始终为正。二者均是二阶动力学，不含隐藏天体。

`physics_version` 写入新会话配置、任务及评测结果。未记录版本的历史会话按 `v1` 评测，保留原世界 03 的逐分量三次背景势和原世界 05 的均匀速度偏转项。显式 `v2` 会话继续使用世界 05 的 `1.2/(rho_i²+4)`；v3保留其原始任务包、静态位置估计和评测输入。世界06/07仅支持v4。版本变化不会重新解释旧数据；世界编号或版本冲突时拒绝评测。单布局的高预测精度仍不能唯一证明源机制，等效展开式同样可能准确预测。

## 绝对时间与观测输入

所有工具使用共同的绝对时间原点t=0。投放时刻t0只改变探针开始时间，样本时刻为t0加相对偏移，不重置源运动或周期相位。思考时间和请求顺序不推进物理世界。请求时刻对齐0.005网格；数值积分器内部仍使用连续时间，不能把内部时刻取整到网格。

v4按天体编号、绝对时刻聚合观测，只对同一时刻的重复测量求均值；已知t=0位置优先于该时刻的带噪读数。模型中的 `sum_b` 使用该积分时刻的源位置。当前工具采用观测点间分段线性插值，不擅自外推；使用源位置的候选若超出观测覆盖，会返回 `body_time_coverage`，Agent需补充observe。仅依赖t/r/v的展开式不要求源覆盖。当前世界06无噪声时的匀速轨迹可被此插值精确表示；一般运动、带噪数据存在插值误差，不应全归因于力场不对。

law冻结公式、参数和训练时的输入快照。验证与残差可使用新增的合法源观测，但每次保存独立输入快照，不修改law、旧验证或旧残差。源状态是外部观测输入，不是额外拟合参数。提交的 `acceleration(t,bodies,params)` 接收调用方提供的当前可见天体状态；PDF未细化其正式数据编码，本项目的状态适配是本地契约。

会话后v4评测以真实瞬时可见源位置作为该外部输入，测试冻结力场和参数的预测能力，不同时测量源轨迹插值质量。此真值只在会话结束后的评测进程中使用，不回传给探索Agent。旧版评测仍使用旧规则下冻结的源位置，因此不能把v4与旧版带噪误差直接混比。

## 运行与评测

启动网页：

```bash
cd virtual_physics_law_explore
.venv/bin/python -m shore_agent.web --port 8765
```

打开 `http://127.0.0.1:8765`，选择世界并开始探索。命令行也可用 `--world` 覆盖配置：

```bash
.venv/bin/python -m shore_agent.cli run --world world_3 --run-dir runs/my-world-3
```

命令行真实模型运行需要 `DEEPSEEK_API_KEY`。密钥不应写进配置或运行记录。

独立评测从会话保存的世界及物理版本选择参考轨迹；只有已受理且已结束的提交才能评测。世界01使用解析轨迹，世界02使用矩阵指数，世界03/04/05/06/07使用独立的高精度Radau积分（区别于观测仿真的DOP853）；世界06另有移动参考系解析解的交叉测试。数值参考不宣称解析真值；旧版世界05仍使用矩阵指数。评测使用未见初态、绝对物理时间和无观测噪声的参考，不将结果回传运行中的Agent。

首轮基准为每世界一次、无噪声、相同种子和相同预算。结果应同时报告提交状态、未提交原因、未见初态位置与速度 RMSE、工具失败和模型用量；受理不等于发现正确规律，未提交不能算成功。每世界一次只用于检查能力与失败模式，不是稳定成功率估计。

旧版首轮结果见 [五世界测试报告](five-worlds-results.md)，扩大预算后的第二轮见 [第二轮报告](five-worlds-large-budget-results.md)。这些报告保留当时的工具与提示词配置；当前单 Agent 版本的新批次运行方式见 [基准运行说明](benchmark.md)。
