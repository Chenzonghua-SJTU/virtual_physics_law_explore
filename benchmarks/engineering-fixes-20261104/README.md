# 表达式、预算及数值精度修复验证

2026-11-04，在 v0.1.0 基础上修复上一轮七世界测试发现的三个工程问题。此记录是**离线工程回归，不是新一轮自主探索成绩**，没有调用模型。原始七次运行档案的文件哈希在回放前后完全一致。

## 修改范围

- 表达式总 AST 上限由 100 提至 256，深度、最多五个参数、常量规则和语法白名单保持原约束。报错包含实际节点数量，并说明资源限制不构成对物理假设的检验。任务语法说明同步更新，主 Agent 提示词文件不变。
- 下一轮预算使用服务商已报告的、完全相同消息前缀的 prompt token 数，加新增消息 UTF-8 字节上界及 512 token 协议余量。旧消息、思考内容、工具或模型配置改变时退回整包字节预估；不删历史、不把缓存命中视为免费。实际 usage 仍是累计用量的依据，缺失 usage 时保留预留量。首次请求仍使用原有保守预估。
- 公开噪声水平为零，且粗拟合收敛、位置 RMSE 不超过训练位置 RMS 的 1e-5 倍（尺度至少为 1）时，允许以 1e-12 容差精修。共享原拟合的时间与计算预算；若精修失败、未收敛或误差变大，保留粗拟合结果。噪声非零或未知时不启用。验证和提交继续使用冻结参数。

不调整物理解释生成与评分，不改变七个世界的底层物理规律。新探索会加载更新后的独立 worker；现有会话和历史结果不重写，网页刷新即可加载新版静态资源。
